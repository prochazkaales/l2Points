# Glass UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Celá aplikace v jednotném „minimal glassmorphism“ vzhledu (dark i light), s čitelnější mřížkou Můj týden, bez změny funkcí.

**Architecture:** Barvy jsou CSS proměnné pod `:root[data-theme="dark|light"]` v `wwwroot/app.css`; atribut nastaví inline skript v `<head>` ještě před vykreslením a `MainLayout` z něj převezme počáteční režim MudBlazoru. Sklo je globální CSS (třída `.l2p-glass` + selektory na outlined `MudPaper`/`MudTable` uvnitř `.mud-main-content`), MudBlazor `Surface` zůstává neprůhledný, takže popovery a dialogy průhledné nejsou. Jediná nová logika je klasifikace stavu buňky mřížky (čistá funkce, TDD).

**Tech Stack:** .NET 10, Blazor Web App, MudBlazor 9.x, xUnit, Outfit (OFL, self-hosted woff2).

**Spec:** `docs/superpowers/specs/2026-10-29-glass-ui-design.md` (vizuální reference: plátno odkazované ve specu)

## Global Constraints

- Větev `feature/glass-ui` (už existuje, založená z `feature/favicon`); commit messages anglicky, komentáře a názvy anglicky, UI česky.
- Hodnoty barev přesně podle tabulek „Paleta a tokeny“ ve specu; text na plné primary: dark `#0B0A1A`, light `#FFFFFF`.
- Žádná další UI knihovna ani externí CDN; font jen self-hosted v `wwwroot/fonts/`.
- Blur (`backdrop-filter: blur(20px) saturate(140%)` + `-webkit-` prefix) jen na app baru, draweru a kartách sekcí; nikdy na řádcích, buňkách, chipech.
- Popovery, menu, select, dialogy, tooltipy, snackbary a sticky buňky mají neprůhledný povrch (dark `#16132A`, light `#F8F8FD`).
- Kontrast textu ≥ 4,5:1 v obou režimech; obrys nezaškrtnutého checkboxu ≥ 3:1; dotykový cíl checkboxu v mřížce ≥ 40×40 px pod 600 px šířky.
- Žádná změna doménové logiky, služeb, rout, autorizace ani pravidel úprav.
- Aktuální čas jen přes `TimeProvider`; styly na kořeny `MudPaper`/`MudTd`/`MudTh` jen globálně v `app.css` (scoped CSS na ně nedosáhne).
- TDD jen pro `GridCellStates` a `DisplayFormat.StatCategoryKey`; zbytek se ověřuje ve spuštěné aplikaci (preview `l2points-web`, `http://localhost:5167`, dev admin z `appsettings.Development.json`).

## Review Focus

1. Uživatel má uloženou volbu „light“, ale OS je tmavý (a naopak): první vykreslení po načtení i po F5 musí být rovnou ve zvoleném režimu, žádný záblesk druhého režimu (pozadí, placeholder, MudBlazor paleta). Ověřuje Task 1, krok „Ověř bez přebliknutí“.
2. `localStorage` je zablokovaný (private mode, `try/catch`): skript v `<head>` nesmí spadnout, použije `prefers-color-scheme`; přepínač tématu funguje jen pro aktuální stránku. Ověřuje Task 1.
3. Mřížka na `/players/{Id}` (jen ke čtení) a mřížka během ukládání (`ReadOnly="_loading"`) nesmí vybledout ani problikávat; zamčené buňky v Můj týden naopak musí být zřetelně jiné. Pokrývá test `GridCellStatesTests` a vizuální kontrola v Task 4.
4. Otevřený `MudSelect`/`MudMenu`/dialog nad skleněnou kartou nesmí být průhledný; sticky sloupec nicku a bossů při vodorovném scrollu nesmí propouštět obsah pod sebou. Ověřuje Task 3 (výběr hráče v `/admin/attendance`, dialog v `/admin/players`, scroll tabulky na 375 px).
5. Prohlížeč bez `backdrop-filter` nebo s `prefers-reduced-transparency: reduce`: karty dostanou neprůhledný povrch a text zůstane čitelný. Ověřuje Task 3 (emulace přes dočasné vypnutí pravidla v DevTools / `javascript_tool`).
